# Mi Primer Proyecto Flask - Contaminación

## 📌 Descripción

Este proyecto es una aplicación web básica desarrollada con Python y el framework Flask. El proyecto está enfocado en el tema de la contaminación y presenta información relacionada con sus causas, consecuencias y la importancia de cuidar el medio ambiente. 🌎♻️

## 🎯 Propósito del proyecto

El propósito de este proyecto es conocer y comprender el problema de la contaminación y cómo puede afectar al medio ambiente y a los seres vivos. También busca presentar información de manera sencilla para crear conciencia sobre la importancia de reducir la contaminación y cuidar nuestro entorno.

A través de esta aplicación se pretende que los visitantes puedan conocer más sobre este tema y reflexionar sobre algunas acciones que pueden ayudar a proteger el medio ambiente. 🌱

## 🛠️ Tecnologías utilizadas

- Python 🐍
- Flask 🌐
- HTML
- CSS
- python-dotenv

## 📂 Estructura del proyecto

- `app.py` → archivo principal de la aplicación.
- `templates/` → contiene las páginas HTML.
- `static/css/` → contiene los estilos CSS.
- `.env` → contiene las variables de configuración.
- `requirements.txt` → contiene las dependencias del proyecto.

## 📄 Páginas

- 🏠 **Inicio:** presentación del proyecto.
- 🌎 **Acerca de:** información y propósito del proyecto.
- 📩 **Contacto:** información para comunicarse sobre el proyecto.
